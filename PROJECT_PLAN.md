# Plan del Proyecto Rapidin 🗺️

## Fase 1: MVP Funcional (Fase Actual)
- ✅ Diseño de interfaces web (UI/UX) para Cliente y Repartidor.
- ✅ Configuración del servidor Backend en Node.js y base de datos SQLite.
- ✅ Implementación de carrito de compras y catálogo.
- ✅ Simulaciones en vivo de seguimiento GPS con WebSockets.

## Fase 2: Desarrollo y Integración
- 🔲 **Portal para Comercios:** Interfaz web para que los restaurantes acepten y administren pedidos.
- 🔲 **Pasarela de Pagos Reales:** Integración con servicios de pago (ej. Stripe, PayPal o MercadoPago).
- 🔲 **Migración de Base de Datos:** Cambiar SQLite por una base de datos más robusta como PostgreSQL en la nube.
- 🔲 **Notificaciones Push:** Integración con Firebase (FCM) para alertas instantáneas.
- 🔲 **PWA / App Nativa:** Convertir el sitio web en una PWA completa o empaquetar con Capacitor/React Native para tiendas de apps.

## Fase 3: Despliegue (Producción)
- 🔲 Despliegue del backend en un entorno de producción (Render, Heroku o AWS).
- 🔲 Alojamiento del frontend usando Vercel o Netlify.
- 🔲 Optimización y seguridad (HTTPS, CDN para imágenes).
- 🔲 Fase beta de prueba con usuarios y repartidores reales en una ciudad piloto.
